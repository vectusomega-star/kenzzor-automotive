KENZZOR AUTOMOTIVE — WEBSITE V4
================================

FILES
- index.html: complete responsive website (HTML, CSS and JavaScript)
- assets/: original SVG K shield and concept-car illustrations

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository. For a normal public project repository, a name such as `kenzzor-website` is fine.
2. Set repository visibility to Public.
3. Open the repository and choose Add file > Upload files.
4. Upload `index.html` and the entire `assets` folder. Keep the folder structure unchanged.
5. Commit the upload to the `main` branch.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select Branch: `main`, Folder: `/ (root)`, then Save.
9. Wait for GitHub Pages to publish. The public address will look like:
   https://YOUR-USERNAME.github.io/kenzzor-website/

IMPORTANT
- Upload the contents of this ZIP, not the ZIP file itself.
- Keep `index.html` at the repository root.
- Keep the `assets` folder beside `index.html`.
- The website is a concept-brand showcase. Vehicle specifications and production claims are intentionally marked unconfirmed.
- The SVG vehicle illustrations are original stylized concept artwork, not engineering-accurate 3D models.
